# Resume2Interview Demo Video Production Guide

## 🎬 Video Specifications

**Target Length:** 60-90 seconds
**Format:** 1920x1080 (16:9) or 1280x720
**Frame Rate:** 30fps
**File Format:** MP4 (H.264 codec)
**Audio:** Clear voiceover with background music (optional)
**Hosting:** YouTube (public, embed on site)

## 🎥 Recording Instructions

### **Pre-Recording Setup**

1. **Prepare Sample Data:**
   - Use a realistic sample resume (create/use anonymized version)
   - Prepare a real job description (Software Engineer, Product Manager, etc.)
   - Pre-copy the job description to clipboard for smooth pasting

2. **Clean Your Screen:**
   - Close unnecessary tabs/windows
   - Use clean browser profile (no extensions visible)
   - Clear browser history (clean address bar)
   - Use incognito mode to avoid autocomplete

3. **Browser Settings:**
   - Zoom level: 100% or 110% (for readability)
   - Window size: Full screen or maximized
   - Hide bookmarks bar

### **Recording Tools**

**Option 1: Loom (Easiest)**
- URL: https://www.loom.com/
- Free for up to 5 minutes
- Records screen + webcam (optional)
- Automatic hosting and embedding
- **Pros:** Easiest, fastest
- **Cons:** Loom branding on free plan

**Option 2: OBS Studio (Professional)**
- URL: https://obsproject.com/
- Free and open-source
- No watermarks
- Professional features (scenes, transitions)
- **Pros:** Full control, no watermarks
- **Cons:** Steeper learning curve

**Option 3: Camtasia (Paid)**
- URL: https://www.techsmith.com/video-editor.html
- 30-day free trial
- Built-in editing features
- **Pros:** Easy to use, professional results
- **Cons:** $299 (but free trial works)

**Option 4: Windows Built-in (Quick & Free)**
- Press **Win + G** to open Game Bar
- Click **Record** button
- **Pros:** Already installed, free
- **Cons:** Basic features only

**Recommendation:** Start with **Loom** for speed. If you don't like the branding, re-record with **OBS Studio**.

---

### **Recording Checklist**

**Before Recording:**
- [ ] Close all unnecessary applications
- [ ] Mute notifications (Focus Assist on Windows)
- [ ] Test microphone audio quality
- [ ] Practice the flow 2-3 times without recording
- [ ] Have script visible on second monitor or printed

**During Recording:**
- [ ] Speak clearly and at moderate pace
- [ ] Pause 2 seconds between major steps (easier to edit)
- [ ] Move mouse smoothly (not too fast)
- [ ] Highlight important elements (cursor hover)
- [ ] Don't rush - 90 seconds is plenty of time

**After Recording:**
- [ ] Watch full video
- [ ] Check audio levels (not too quiet or loud)
- [ ] Verify all key features are shown
- [ ] Re-record if needed (it's okay!)

## 🎨 Post-Production Editing

### **Basic Edits (Required)**

1. **Trim:**
   - Remove dead air at beginning/end
   - Cut out mistakes or long loading times
   - Speed up slow sections (1.5x - 2x)

2. **Add Text Overlays:**
   - Title at start: "Resume2Interview - AI Resume Tailoring"
   - Key benefits: "ATS Score: 78/100", "15 Recommendations"
   - Call-to-action at end: "Try FREE at resume2interview.com"

3. **Add Arrows/Highlights (Optional):**
   - Point to important UI elements
   - Highlight clicked buttons
   - Draw attention to scores

### **Advanced Edits (Optional)**

4. **Background Music:**
   - Use royalty-free music (low volume)
   - Sources: YouTube Audio Library, Epidemic Sound
   - Keep it subtle and professional
   - **Recommended track style:** Upbeat, tech, corporate

5. **Transitions:**
   - Simple fade between major sections
   - Don't overdo it - keep professional

6. **Branding:**
   - Logo in corner (optional)
   - Brand colors in text overlays

### **Editing Tools**

**Free:**
- **DaVinci Resolve** (professional, free)
- **iMovie** (Mac only)
- **Clipchamp** (online, easy)

**Paid:**
- **Camtasia** (easiest)
- **Adobe Premiere Pro** (professional)

## 💡 Pro Tips

1. **Keep it simple:** Don't try to show every feature. Focus on core value.
2. **Use real data:** Realistic resumes and job descriptions are more convincing.
3. **Show results fast:** Get to the analysis results within 30 seconds.
4. **End with CTA:** Always include clear call-to-action at the end.
5. **Mobile-first:** Ensure video is viewable on mobile devices.
6. **Captions:** Add captions for accessibility and silent viewing.
7. **Iterate:** Record multiple versions if needed. First attempt rarely perfect.
